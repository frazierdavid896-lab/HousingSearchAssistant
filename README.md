# Housing Search Assistant v0.3

Adds official City of Little Rock park polygons to the existing school screening.

## Install
Copy all files into:
C:\\Users\\frazi\\Documents\\HousingSearchAssistant

## Run
```powershell
streamlit run app.py
```

A PASS currently means no loaded K–12 school or public park was found within 2,000 feet. Daycare coverage is not yet included.
